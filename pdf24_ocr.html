Cara mengenali teks

Pilih file PDF yang ingin diterapkan OCR atau letakkan file ke dalam kotak file. Ubah pengaturan dan mulai OCR. Setelah beberapa detik Anda dapat mengunduh file PDF Anda yang dapat dicari.

Pengaturan OCR

Anda dapat mengubah beberapa pengaturan untuk mengontrol proses OCR. Anda dapat menyimpan sebagai PDF/A, menghapus artefak dan bintik, meluruskan halaman, mengatur informasi meta, dan menggabungkan file menjadi satu file keluaran.

Mudah digunakan

PDF24 membuatnya semudah mungkin agar Anda dapat mengenali teks melalui OCR. Tidak perlu menginstal dan memikirkan perangkat lunak apa pun, cukup pilih file yang ingin diterapkan OCR.

Mendukung sistem Anda

Tidak perlu sistem khusus untuk mengenali teks melalui OCR. Aplikasi OCR ini berjalan di browser Anda dan berfungsi di semua sistem operasi. Cukup masukkan file Anda dan mulai OCR.

Tidak perlu instalasi

Tidak perlu mengunduh atau menginstal perangkat lunak apa pun. Teks dikenali di server kami di cloud, sehingga tidak menggunakan sumber daya komputer Anda.

Keamanan sangat penting bagi kami

Alat OCR ini tidak menyimpan file Anda di server kami lebih lama dari yang diperlukan. File dan hasil Anda akan dihapus dari server kami paling lambat satu jam setelah penggunaan terakhir. Transmisi file dijamin SSL.

Apa yang orang lain katakan

Alat ini membuat saya bisa menerapkan OCR ke pindaian dokumen dan faktur dengan sangat mudah. Saya mendapatkan PDF/A yang bisa dicari kembali untuk pengarsipan.
Saya menggunakan alat ini untuk mengonversi gambar dan foto yang diambil dengan ponsel pintar saya ke dalam PDF yang dapat dicari, sehingga saya dapat mencari dan menyalin teks.

Pertanyaan dan Jawaban

Bagaimana mengenali teks dalam file menggunakan OCR?

  1. Gunakan kotak pilihan file di bagian atas halaman untuk memilih file yang teksnya ingin dikenali.
  2. Ubah pengaturan untuk memberi tahu aplikasi cara kerja pengenal teks.
  3. Mulai proses pengenalan dengan menekan tombol yang sesuai.
  4. Tekan tombol Unduh untuk menyimpan PDF yang teksnya sudah dikenali ke komputer Anda.
